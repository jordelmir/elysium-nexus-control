## Phases (recap, see full text in `MASTER_ORDER_SECTIONS.md` §42)

* **Phase 0** — Investigation: architecture map, threat model, standards report,
  open-source audit, licensing matrix, target matrix, risk register, ADRs,
  minimal POCs.
* **Phase 1** — Android universal controller (touch engine, editor, sticks,
  buttons, triggers, D-pad, gyro, profiles, haptics, persistence, tests).
* **Phase 2** — Direct HID (Bluetooth HID, generic gamepad descriptor, keyboard,
  mouse, Android host, macOS, Windows, Linux, compatibility database).
* **Phase 3** — Desktop agents (macOS / Windows / Linux with secure pairing,
  virtual devices, profiles, diagnostics, release-all).
* **Phase 4** — Nexus Receiver (hardware selection, board prototype, Elysium
  Link, USB HID, BLE, Wi-Fi, secure boot, firmware updates, hardware-in-loop CI).
* **Phase 5** — Remote Companion (PS4/5 Remote Play, Xbox Remote Play, Xbox
  cloud, foldable experience, network diagnostics).
* **Phase 6** — Licensing (PS application, Designed for Xbox, Nintendo inquiry,
  business docs, certification planning, secure backend interfaces).
* **Phase 7** — Certified console support (only with SDK + authorization).

The first execution (§45) tells us the first *milestone* is not the whole of
Phase 1: it's a small, measurable, *deterministic* slice where the APK on
Honor Magic V2 emits generic HID (or Elysium Link) and the host sees buttons /
D-pad / sticks / triggers / motion, and an abrupt disconnect neutralizes
everything. We are working toward that milestone.
